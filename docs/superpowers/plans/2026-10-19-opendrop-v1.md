# Layover v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a sandboxed macOS menu-bar app where a Shake during a drag (or a hotkey / menu command) opens a floating Shelf that collects Items and lets you drag them out again.

**Architecture:** All logic that doesn't need the UI lives in a Swift package (`LayoverKit`) with two library targets. `LayoverCore` (Foundation only) holds the Shake detection, the model, the lifecycle and persistence. `LayoverUI` (AppKit/SwiftUI) holds windows, system integration and preferences. A thin app target, generated by XcodeGen, wires them together. `swift test` exercises the package without Xcode. The app bundle itself requires Xcode.

**Tech Stack:** Swift 6 (language mode 6, strict concurrency), AppKit, SwiftUI (Settings only), Swift Testing, XcodeGen, Sparkle 2, Carbon `RegisterEventHotKey`, `SMAppService`.

**Spec:** the v1 design spec in `docs/superpowers/specs/` — read it with `GLOSSARY.md`, `docs/adr/0001-sandboxed-from-day-one.md` and `docs/research/dropover-teardown.md` §3.

## Global Constraints

- Deployment target macOS 14.0; Swift language mode 6.
- App Sandbox on, hardened runtime on. No Accessibility, Input Monitoring or CGEventTap.
- `LSUIElement = YES`.
- Bundle identifier `dev.mauipingol.Layover` (keep it in one place, `project.yml`).
- Domain words exactly as in `GLOSSARY.md`: Shelf, Item, Owned File, Handle, Shake, Ignored App, Unavailable Item, Recent Shelf, Pinned Shelf. Never "session", "draggable" or "stash" in type names or UI copy.
- Every user-facing string goes through `String(localized:)` and lives in `App/Resources/Localizable.xcstrings`.
- Recent Shelf limit: 10. Shake timing: max event gap 0.2 s, gesture window 1.0 s.
- No analytics or crash-reporting SDKs. The only third-party dependency is Sparkle.
- Before running `swift test`, make sure no other `swift test`/`swift-build` process is running (`pgrep -fl swift-build`). Never start overlapping runs.
- Git: work on branch `feat/v1` (create it before Task 1). Every "Commit" step means **ask the user before committing**. Use Conventional Commits, with no AI or tool attribution in messages.

## Review Focus

1. Dragging an Item into an app that *copies* (Mail, a browser upload field, Slack) must leave the Item on the Shelf and the original untouched. Only a reported `.move` removes Items. Pinned in Task 10 (`DragOutcomeTests`).
2. An original file moved to the Trash must count as **deleted**, not "followed to the Trash". Pinned in Task 3 (`resolveTreatsTrashAsDeleted`).
3. A corrupt or newer-version `shelves.json` must not block launch, and must not be silently overwritten. Pinned in Task 6 (`loadSetsAsideCorruptFile`, `loadSetsAsideFutureVersion`).
4. Shaking while dragging something that isn't content (moving a window, selecting text) must not open a Shelf. Pinned in Task 2 (`noPasteboardChangeNeverFires`).
5. A Shelf opening on a secondary display (negative coordinates) or at a screen corner must land fully on that screen. Pinned in Task 8 (`ShelfPlacementTests`).

### Task 2: Shake trigger (when a Shake opens a Shelf)

**Files:**
- Create: `LayoverKit/Sources/LayoverCore/Shake/ShakeTrigger.swift`
- Test: `LayoverKit/Tests/LayoverCoreTests/ShakeTriggerTests.swift`

**Interfaces:**
- Consumes: `ShakeDetector`, `ShakeSensitivity` (Task 1).
- Produces:
  ```swift
  public struct DragSample: Sendable { public var location: CGPoint; public var time: Date
      public var isOverShelf: Bool; public var ownerBundleID: String? }
  public struct ShakeTrigger: Sendable {
      public init(sensitivity: ShakeSensitivity, ignoredBundleIDs: Set<String>)
      public mutating func dragMoved(_ sample: DragSample) -> CGPoint?   // non-nil = open a Shelf here
      public mutating func dragPasteboardChanged() -> CGPoint?           // non-nil = open a Shelf at last location
      public mutating func mouseUp() }                                    // ends the drag; next dragMoved starts a new one
  ```

Rules: a drag starts with the first `dragMoved` after init or `mouseUp`. If that first sample `isOverShelf`, the whole drag is suppressed. The trigger fires when the detector is recognized **and** the pasteboard changed during this drag, in either order, at the first moment both hold. It doesn't fire if the current (or, for `dragPasteboardChanged`, the last) sample's `ownerBundleID` is ignored; it can still fire later over another app. It fires at most once per drag. `.off` never fires.

**Files:**

- Test: `LayoverKit/Tests/LayoverCoreTests/FileReferenceTests.swift`, `ShelfTests.swift`

**Interfaces:**
- Produces:
  ```swift
  public struct FileIdentity: Codable, Hashable, Sendable { public var volumeUUID: String; public var fileID: UInt64
      public init(of url: URL) throws }       // .volumeUUIDStringKey + .fileIdentifierKey
  public protocol MountedVolumes: Sendable { func isMounted(volumeUUID: String) -> Bool }
  public struct SystemMountedVolumes: MountedVolumes { public init() }
  public struct FileReference: Codable, Hashable, Sendable {
      public var bookmark: Data; public var lastKnownPath: String; public var identity: FileIdentity
      public static func make(for url: URL, securityScoped: Bool = true) throws -> FileReference
      public func resolve(volumes: MountedVolumes, securityScoped: Bool = true) -> FileResolution }
  public enum FileResolution: Equatable, Sendable { case available(URL, updated: FileReference?), deleted, unavailable }
  public struct OwnedFile: Codable, Hashable, Sendable { public var id: UUID; public var filename: String; public var kind: Kind
      public enum Kind: String, Codable, Sendable { case text, link, image, received } }   // received = file promise (Task 9)
  public enum ItemContent: Codable, Hashable, Sendable { case file(FileReference), owned(OwnedFile) }
  public struct Item: Codable, Hashable, Identifiable, Sendable { public var id: UUID; public var content: ItemContent }
  public struct Shelf: Codable, Hashable, Identifiable, Sendable {
      public let id: UUID; public var createdAt: Date; public var isPinned: Bool; public var frame: CGRect?; public var items: [Item]
      public init(id: UUID = UUID(), createdAt: Date = .now)
      public enum AddOutcome: Equatable, Sendable { case added(Item.ID), duplicate(of: Item.ID) }
      public mutating func add(_ content: ItemContent, id: UUID = UUID()) -> AddOutcome
      public mutating func remove(_ ids: Set<Item.ID>)
      public var ownedFileIDs: Set<UUID> }
  ```

`resolve` rules: resolve the bookmark with `.withoutUI` and `.withoutMounting` (plus `.withSecurityScope` when `securityScoped`). If it resolves to an existing file whose path doesn't contain a `/.Trash/` component → `.available`, with `updated` non-nil when the bookmark was stale or the path changed. If it resolves into a Trash → `.deleted`. If it fails → `.deleted` when `volumes.isMounted(identity.volumeUUID)`, else `.unavailable`.

Duplicate rule: a `.file` whose `identity` equals an existing `.file` Item's identity → `.duplicate(of:)`, and nothing is added. `.owned` content is never a duplicate.

### Task 5: Shelf library (lifecycle)

**Files:**
- Create: `LayoverKit/Sources/LayoverCore/Library/LibrarySnapshot.swift`, `ShelfLibrary.swift`
- Test: `LayoverKit/Tests/LayoverCoreTests/ShelfLibraryTests.swift`

**Interfaces:**
- Consumes: `Shelf` (Task 3).
- Produces:
  ```swift
  public struct LibrarySnapshot: Codable, Equatable, Sendable {
      public static let currentVersion = 1
      public var version: Int; public var pinned: [Shelf]; public var recent: [Shelf]
      public static let empty: LibrarySnapshot }
  public struct ShelfLibrary: Equatable, Sendable {
      public static let recentLimit = 10
      public private(set) var open: [Shelf]; public private(set) var recent: [Shelf]   // recent: newest first
      public init(snapshot: LibrarySnapshot)                  // open = pinned, recent = recent
      @discardableResult public mutating func newShelf(id: UUID = UUID(), createdAt: Date = .now) -> Shelf.ID
      public mutating func update(_ shelf: Shelf)             // replaces the open Shelf with the same id
      public mutating func close(_ id: Shelf.ID)              // non-empty → front of recent (capped); empty → discarded
      @discardableResult public mutating func reopen(_ id: Shelf.ID) -> Bool   // recent → open
      public mutating func removeRecent(_ id: Shelf.ID)
      public mutating func clearRecent()
      public func snapshot() -> LibrarySnapshot
      public var referencedOwnedFileIDs: Set<UUID> }          // open + recent
  ```

`snapshot()`: `pinned` = open pinned Shelves. `recent` = non-empty open unpinned Shelves (newest `createdAt` first), followed by `recent`, capped at 10. Saving a snapshot is therefore equivalent to quitting, so a crash behaves like a quit.

### Task 9: Dropping into a Shelf

**Files:**
- Create: `LayoverKit/Sources/LayoverUI/Shelf/ItemImporter.swift`
- Modify: `ShelfViewController.swift` (register as dragging destination; bounce on duplicate)
- Test: `LayoverKit/Tests/LayoverUITests/ItemImporterTests.swift`

**Interfaces:**
- Consumes: `OwnedFileStore`, `FileReference.make`, `ItemContent` (Tasks 3–4).
- Produces:
  ```swift
  public struct ItemImporter: Sendable {
      public init(ownedFiles: OwnedFileStore, securityScoped: Bool = true)
      public static let acceptedTypes: [NSPasteboard.PasteboardType]   // .fileURL, .URL, .png, .tiff, .string, + NSFilePromiseReceiver.readableDraggedTypes
      public func contents(from pasteboard: NSPasteboard) throws -> [ItemContent]
      public func receivePromises(from pasteboard: NSPasteboard) async throws -> [ItemContent] }
  ```

`contents(from:)` precedence (first match wins for the whole drop):
1. File URLs → one `.file` per URL.
2. A web URL (http/https) → `.owned(link)`, titled from `public.url-name` when present.
3. PNG or TIFF data → `.owned(image)` (TIFF converted to PNG).
4. A string → `.owned(text)`.

If a file URL can't be bookmarked, it's skipped; the others still import.

`receivePromises`: used when the pasteboard holds file promises and no file URLs (images from browsers, Mail attachments). Each promised file is received into a fresh `<ownedDir>/<uuid>/` directory and becomes an `OwnedFile` with `kind = .received` and the promised filename. Otherwise the drop goes through `contents`.

The drop handler adds each content item to the Shelf. On `.duplicate(of:)`, the existing Item's view runs a 0.25 s scale bounce (1.0 → 1.15 → 1.0). Duplicates never raise an error.
