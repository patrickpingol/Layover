# Layover v1 — design

Vocabulary: see `GLOSSARY.md` (Shelf, Item, Owned File, Handle, Shake, Ignored App, Unavailable Item, Recent Shelf, Pinned Shelf).
Background: `docs/research/dropover-teardown.md`. Architectural decision: `docs/adr/0001-sandboxed-from-day-one.md`.

## Product

1. Open source (MIT), direct download, not App Store for now.
2. Native Swift; AppKit for the app core; SwiftUI only for Settings. Minimum macOS 14.
3. App Sandbox, hardened runtime and notarization from day one.
4. Sparkle for updates. No analytics, no crash reporting.
5. English only, with all user-facing strings in a String Catalog.
6. Xcode project generated by XcodeGen from a checked-in `project.yml`.

## v1 scope

In:
- Menu-bar agent (`LSUIElement`), no Dock icon.
- New Shelf from the menu bar menu or a global hotkey. The default is ⌃⌥⌘N; if it clashes with a system shortcut on first launch, it's left unassigned.
- **Shake** opens a new Shelf at the cursor during a drag. Sensitivity is Off / Normal / High / Highest (default Normal), plus a list of Ignored Apps.
- Drop into a Shelf: files, text, links and images. Drag out of a Shelf. Several Shelves can be open at once.
- Persistence of Shelves and a Recent Shelves menu.
- Item actions: Open, Reveal in Finder, Quick Look, Copy, Remove, Share (system share menu: AirDrop, Mail, …).

Out (deferred): modifier-key trigger, notch, edge docking and retract, Instant Actions, file transforms, folder and screenshot watching, cloud links, Shortcuts/App Intents, share extension, widget.

## Shake

Horizontal-only reversal counting (algorithm in the teardown §3.2). All levels: max 0.2 s between drag events and a 1.0 s gesture window.

| Level | Recognized when reversals > | Min stroke |
|---|---|---|
| Normal | 4 | 20 pt |
| High | 3 | 15 pt |
| Highest | 2 | 10 pt |

A Shake opens a Shelf only if the same drag is seen carrying real content, in either order: the drag pasteboard changed, or a drag image is on screen (a Dock stack drag shows one but leaves the drag pasteboard untouched). It doesn't fire if the drag started on a Shelf or the window under the cursor belongs to an Ignored App. It fires at most once per drag. A Shake always opens a **new** Shelf.

## Shelves and Items

- A file Item references the original file in place (security-scoped bookmark); it is never copied on drop.
- Text, links and images that aren't files become Owned Files: `.txt`, `.webloc`, `.png`.
- Every new Shelf opens next to the cursor, kept fully on the cursor's screen. There's no placement setting.
- Look: a compact stack (thumbnails, Item count, Handle) that expands into an icon grid on click. No list view.
- Dropping a file already on the Shelf (same file on disk, not just the same path) is ignored, and the existing Item bounces.
- Dragging the compact stack or the Handle drags all Items; a click on the stack expands it. Dragging an Item in the grid drags the selection, or just that Item. Both work on the first click, even when the Shelf is not focused.
- Drag-out moves by default; holding ⌥ copies. Items leave the Shelf only when the destination performed a move.
- "Close Shelf when emptied" (default **on**): a Shelf closes once a move empties it. A copy never closes it.
- Renamed or moved originals are followed. A deleted original removes its Item and shows a notice: "'<name>' was removed from disk." An original on an ejected disk leaves an Unavailable Item (greyed).

## Lifecycle

- Closing a non-empty Shelf makes it a Recent Shelf. The 10 most recent are kept. Closing an empty Shelf discards it.
- Pinned Shelves stay open until closed and reappear after relaunch.
- Unpinned Shelves that are open when Layover quits become Recent Shelves.
- Owned Files are deleted once no open Shelf or Recent Shelf refers to them. Copies the user dragged out are never touched.

## Settings (v1, exactly)

Launch at login (asked once on first run) · Shake on/off and sensitivity · Ignored Apps · New Shelf hotkey · Close Shelf when emptied · Show in menu bar.

## Testing

Automated tests cover the logic that doesn't need the UI: Shake detection, persistence, the Recent Shelf cap, duplicate detection, Owned File cleanup. System integration and windows are verified by hand with a written checklist.
